title: Vercel webhook
description: Send Vercel events to the relay

---

Account webhooks are a Pro and Enterprise feature. In the Vercel dashboard, open **Settings → Webhooks** for the team that owns the projects you want to watch.

Create a webhook:

- **URL**: your API's public origin, plus `/hooks/vercel`
- **Events**: Deployment Created, Succeeded, Error, Canceled, Promoted, and Rollback

Skip Deployment Cleanup, Build Requested, Blocked, Checkrun, and Attack Detected. An unknown event name gets `400`.

Copy the secret from the create dialog into `WEBHOOK_INTEGRATION_SECRET`, then recreate the container. The dialog shows it once. An integration webhook uses the Integration Console client secret in that same variable.

A team webhook covers every project on the team. A project webhook covers that project. One process, one secret.

A bad signature is `401`. An accepted or filtered event is `200`. Delivery happens after that response. Each POST logs `hooks/vercel` and the status.

`GET /hooks/vercel` is `405`. A redirect or a challenge page drops the POST.
