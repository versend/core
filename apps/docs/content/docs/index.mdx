# Versend

Vercel signs an event. Versend checks it, then posts it to the destinations you set.

You run the relay. These docs are hosted.

## What you configure

- `WEBHOOK_INTEGRATION_SECRET`
- At least one of Discord, Telegram, Slack, ntfy, or Gotify
