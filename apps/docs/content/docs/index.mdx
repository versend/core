# Versend

Versend is a webhook relay. Vercel signs an event, Versend checks the signature, and the event is delivered to the destinations you configured.

These docs are hosted for you. You run the relay as a container.

## What you configure

One secret, and at least one destination:

- `WEBHOOK_INTEGRATION_SECRET` from the Vercel webhook
- Discord, Telegram, HTTP, or any combination

Rate limiting stays inside the process. There is no Redis and no Slack destination.
