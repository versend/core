---
title: ntfy
description: Publish a Vercel event to an ntfy topic
icon: Bell
---

Set `NTFY_URL` to the topic URL, such as `https://ntfy.sh/mytopic` or the same path on your own server. On a public server the topic is the password. See [publishing](https://docs.ntfy.sh/publish/).

`NTFY_TOKEN` is optional. Set it when the topic is protected.

The notification title is the project and status. Tapping it opens the deployment.
