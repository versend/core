# Discord

Set `DISCORD_WEBHOOK_URL` to a channel webhook.

1. Open the channel, then **Edit Channel → Integrations → Webhooks**.
2. Create a webhook and copy its URL.
3. Put that URL in `DISCORD_WEBHOOK_URL`.

`DISCORD_WEBHOOK_USERNAME` and `DISCORD_WEBHOOK_AVATAR_URL` are optional.

One embed per event. The project is the author, the title is the status, and the color follows it.
