---
title: Slack
description: Post a Vercel event into a Slack channel
icon: Hash
---

Set `SLACK_WEBHOOK_URL` to an [incoming webhook](https://docs.slack.dev/messaging/sending-messages-using-incoming-webhooks).

1. Create a Slack app and turn **Incoming Webhooks** on.
2. **Add New Webhook to Workspace** and pick the channel.
3. Copy the `https://hooks.slack.com/services/...` URL.

One card per event. The project, status, and commit are on it, with a color bar for the status.
