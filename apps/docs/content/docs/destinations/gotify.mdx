---
title: Gotify
description: Push a Vercel event to a Gotify application
icon: Smartphone
---

Set `GOTIFY_URL` to the server, with no path, and `GOTIFY_TOKEN` to the application token. The token is shown once, when the application is created. See [push messages](https://gotify.net/docs/pushmsg).

Both values are required. The notification matches ntfy: a title, the message, and a tap that opens the deployment.
